# Sprints

One file per ISO week (`YYYY-Www`, RFC-0115): the capacity, the stories chosen — a task and the
phases planned this week, with P50/P85 from history and the sample size — and at the next Monday
the review (`completed`, `slipped`, three lines of retrospective). Planned in the Section 9
conversation, proposed as a diff, applied by the operator; `nx ledger new sprint` and
`nx ledger plan` write the same format.
